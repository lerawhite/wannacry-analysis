### 0x00401140 - Template Pattern Search

`0x00401140` is a helper function used by `0x004017B0` to locate marker strings inside an SMB packet template.

The function receives a buffer, a search pattern, and a maximum search range. In the observed call, the arguments were:

```text
arg1 = 0x0042E494
       SMB packet template

arg2 = 0x00431278
       "__USERID__PLACEHOLDER__"

arg3 = 0x5F
       95 bytes
```

The function first determines the length of the search pattern using `repne scasb`. It then calculates the last valid position from which the complete pattern can fit within the specified search range.

The main search loop uses `repe cmpsb` to compare the pattern against the template at each successive byte position:

```text
template
   │
   ├── compare pattern
   │      │
   │      ├── match → return current address
   │      │
   │      └── no match → advance by 1 byte
   │
   └── continue until search boundary
```

If the pattern is found, the function returns the address of its first byte in `EAX`. If no match is found within the specified range, it returns `NULL`.

During the observed execution, the search was performed against the SMB template beginning at `0x0042E494`. The function did not modify the template itself; it only located the placeholder. The returned address is subsequently used by `0x004017B0` to construct a modified local copy of the SMB packet.

Therefore, `0x00401140` can be characterized as a bounded byte-pattern search helper:

```c
char *FindPattern(
    char *buffer,
    char *pattern,
    size_t search_size
);
```

Its role in the packet-building chain is:

```text
0x0042E494
SMB packet template
       │
       │ 0x00401140
       │ search for "__USERID__PLACEHOLDER__"
       ▼
address of placeholder
       │
       ▼
0x004017B0
construct modified packet
```

The same helper is subsequently used by `0x004017B0` to locate the `__TREEPATH_REPLACE__` marker before replacing it with the target IPC$ path.
