*`Sence - selects the available randomness source`*

---

---

Random values are subsequently obtained through `0x00407660`. This helper selects the available randomness source based on the global cryptographic provider handle at `0x0070F870`:

```
0x0070F870 == 0
    → rand()

0x0070F870 != 0
    → CryptGenRandom(..., 4)
```

When the CryptoAPI provider initialized by `0x00407620` is available, the function therefore obtains 32-bit values from `CryptGenRandom()` under a critical section.
