`0x00406F00` operates on a buffer in-place using a repeating four-byte XOR operation.

Its core loop is:

```asm
mov dl,[key + (index & 3)]
mov bl,[buffer + index]
xor bl,dl
mov [buffer + index],bl
```

Equivalent pseudocode:

```c
for (i = 0; i < length; i++)
    buffer[i] ^= key[i & 3];
```
