### 0x004017B0 — SMB Tree Connect Packet Construction

`0x004017B0` constructs the SMB1 Tree Connect request used as `send3`. It takes the target IP string and the UID obtained from the preceding SMB Session Setup response, then modifies a predefined packet template at `0x0042E494`.

The function performs the following logical stages:

1. **Build target IPC$ path**
    
    The target IP is inserted into a format string, producing:
    
    ```text
    \\192.168.124.128\IPC$
    ```
    
2. **Locate and replace the SMB UID placeholder**
    
    The function uses [0x00410140](0x00410140.md)  to locate:
    
    ```text
    __USERID__PLACEHOLDER__
    ```
    
    inside the SMB template.
    
    The placeholder is replaced with the two-byte UID obtained from the previous `recv2` response. In the controlled execution, the UID was set to `0x1122`, resulting in:
    
    ```text
    11 22
    ```

1. **Locate and replace the Tree Path placeholder**
    
    The function again uses [0x00410140](0x00410140.md) , this time searching for:
    
    ```text
    __TREEPATH_REPLACE__
    ```
    
    The marker is replaced with the generated UNC path:
    
    ```text
    \\192.168.124.128\IPC$
    ```
    
2. **Update packet length**
    
    After both substitutions, the function recalculates the resulting SMB/NetBIOS packet length and updates the length field at `0x0042E497`.
    
3. **Return final packet size**
    
    The final constructed packet length is returned in `EAX` and subsequently used by the caller for `send3`.
