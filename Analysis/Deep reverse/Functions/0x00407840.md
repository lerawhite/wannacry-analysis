### 0x00407840  Random IPv4 Target Generation and Propagation Worker

`0x00407840` implements the second target-selection path of the propagation module. While `0x00407720` enumerates hosts belonging to the local network, `0x00407840` generates IPv4 addresses independently and forwards reachable targets to the common propagation worker at `0x00407540`.

The function is created repeatedly by `0x00407BD0`. Each instance performs a sequence of target-generation attempts and can create a dedicated `0x00407540` worker for targets that pass the TCP/445 connectivity check.

### Randomness Initialization

At function entry, `0x00407840` initializes the C runtime PRNG using a seed derived from several runtime values:

- `GetTickCount()`
    
- `time(NULL)`
    
- `GetCurrentThread()`
    
- `GetCurrentThreadId()`
    

The resulting value is passed to `srand()`.

Random values are subsequently obtained through [0x00407660](0x00407660.md) . This helper selects the available randomness source based on the global cryptographic provider handle at `0x0070F870`:

```text
0x0070F870 == 0
    → rand()

0x0070F870 != 0
    → CryptGenRandom(..., 4)
```

When the CryptoAPI provider initialized by `0x00407620` is available, the function therefore obtains 32-bit values from `CryptGenRandom()` under a critical section.

### IPv4 Target Generation

The function generates four IPv4 octets. Each random value is reduced using a division by `0xFF`, with the remainder used as the resulting octet.

The first octet receives additional filtering:

```text
0x7F (127) → rejected
>= 0xE0 (224) → rejected
```

This prevents generation of `127.x.x.x` loopback addresses and the `224.x.x.x` and higher multicast/reserved range.

The four values are then converted into a dotted-decimal string using:

```text
"%d.%d.%d.%d"
```

and converted to an IPv4 value through `inet_addr()`.

### TCP/445 Connectivity Gate

The generated address is passed to `0x00407480`, which performs the previously analyzed TCP connectivity check against port `445`.

```text
Random IPv4
    │
    ▼
inet_addr()
    │
    ▼
0x00407480(target, 445)
    │
    ├── failure → discard target
    │
    └── success
```

Only targets that pass this connectivity stage are forwarded to the next propagation layer.

### Propagation Worker Creation

For a reachable target, `0x00407840` creates a new CRT-managed thread executing:

```text
0x00407540(target_ip)
```

The new worker is monitored with:

```text
WaitForSingleObject(hThread, 0x36EE80)
```

where `0x36EE80` equals 3,600,000 ms (60 minutes).

If the wait returns `WAIT_TIMEOUT (0x102)`, the thread is terminated with `TerminateThread()`. The thread handle is then closed with `CloseHandle()`.

This makes `0x00407840` responsible for both randomized target selection and lifecycle management of the per-target propagation worker.

### Repeated Target Generation

After each iteration, the function sleeps for `50 ms` and increments its loop counter.

The loop continues while:

```text
counter < 0xFF
```

so a single `0x00407840` instance can perform up to 254 iterations.

The parent `0x00407BD0` creates this worker repeatedly, passing an iteration value from `0` through `127`. Consequently, the random-target propagation path consists of multiple independently initialized workers, each performing repeated target-generation attempts.

### Relationship to the Common Propagation Path

`0x00407840` doest contain the SMB propagation implementation itself. Instead, it provides targets to the already analyzed `0x00407540` worker.

The resulting architecture is:

```text
0x00407840
    │
    ├── generate random IPv4
    ├── filter invalid first octets
    ├── inet_addr()
    ├── 0x00407480
    │      └── TCP/445 connectivity check
    │
    └── _beginthreadex(0x00407540, target)
                 │
                 ├── 0x00401980
                 ├── 0x00401B70
                 ├── 0x00401370
                 └── 0x004072A0
```

This is the complementary target-selection mechanism to `0x00407720`:

```text
0x00407720
    → local interface/subnet enumeration
    → local-network targets

0x00407840
    → randomized IPv4 generation
    → broader network targets
```

Both paths eventually converge on `0x00407540`, where the SMB-based propagation logic is implemented.

### Conclusion

`0x00407840` is the randomized target-generation component of the propagation module. It generates candidate IPv4 addresses, filters selected non-unicast ranges, verifies TCP/445 connectivity through `0x00407480`, and creates `0x00407540` workers for reachable targets.

The function therefore complements the local-network enumeration performed by `0x00407720` and completes the target-selection layer of the analyzed propagation architecture.
