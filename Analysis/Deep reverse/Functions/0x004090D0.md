*`Sence - Validate Addresses Against the Calculated Range`*

---

---

It converts the candidate address and the two supplied boundaries with `htonl()` and verifies that the address lies within the specified interval.

Conceptually:

```c
bool in_range(uint32_t ip,
              uint32_t lower,
              uint32_t upper)
{
    return lower <= ip && ip <= upper;
}
```

In `0x00409160`, this function is used before inserting additional addresses into the resulting array.

Therefore, `0x004090D0` acts as a **range validation filter** rather than performing network communication.
