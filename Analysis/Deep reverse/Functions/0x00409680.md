 `0x00409680` implements a partition-based recursive sorting algorithm.
The behavior is consistent with a quicksort-style implementation:

```text
unsorted address array
        ↓
partition around pivot
        ↓
sort lower range
        ↓
sort upper range
        ↓
sorted address array
```

The exact sorting implementation is not important for the malware behavior itself; its purpose is to establish deterministic ordering of the collected IPv4 values.
