### 0x00406ED0 - DOUBLEPULSAR XOR Key Derivation

`0x00406ED0` implements the XOR-key derivation algorithm used by the DOUBLEPULSAR SMB implant.

The function accepts a single 32-bit value and performs a sequence of shifts, masks, byte rearrangements, and an XOR with `2 * input`.

Simplified representation:

```c
uint32_t DoublePulsarXorKey(uint32_t s)
{
    uint32_t x =
        (((s & 0x0000FF00) | (s << 16)) << 8) |
        (((s >> 16) | (s & 0x00FF0000)) >> 8);

    return (2 * s) ^ x;
}
```

The corresponding assembly performs the following operations:

```asm

```

The resulting operation is equivalent to the published DOUBLEPULSAR XOR-key calculation:

```text
2 * s XOR
(
    (((s & 0x0000FF00) | (s << 16)) << 8)
    |
    (((s >> 16) | (s & 0x00FF0000)) >> 8)
)
```

This is a direct algorithmic match rather than a contextual similarity. The same derivation is documented in Rapid7's research and Metasploit implementation of the DOUBLEPULSAR SMB protocol.

Within the analyzed sample, the value produced by `0x00406ED0` is subsequently passed into the network/payload-processing path. This provides strong static evidence that the surrounding SMB communication is implementing or interacting with the DOUBLEPULSAR protocol.

Therefore, `0x00406ED0` is identified as the **DOUBLEPULSAR XOR-key derivation routine**.

Further reverse engineering of the remote DOUBLEPULSAR implant and the complete `TRANS2_SESSION_SETUP` protocol is outside the scope of this analysis. The exact algorithmic match is sufficient to establish the DOUBLEPULSAR relationship for the purposes of this research.
